# Equitherm Web

React web application for configuring ESPHome equitherm climate components.

## Features

- Interactive heating curve visualization
- PID parameter tuning
- ESPHome YAML export
- URL parameter sharing
- Preset configuration management

## Development

```bash
pnpm install
pnpm dev
```

## Deployment

Automatically deployed to Netlify on merge to main.

## Related Projects

- [@equitherm/core](https://github.com/equitherm/core) - Core calculation library
